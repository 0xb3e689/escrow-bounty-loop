main.py writes one 279-character plan to /output/entry.txt: an AI agent turns $100 into the most money in 30 days by fixing escrowed bug bounties on algora.io — paid in USDC on merge, claiming only bugs it has already fixed with tests green, and reinvesting half of every payout into LLM credits to run claims in parallel.

## Run it

```sh
python3 main.py
```
